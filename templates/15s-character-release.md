# 15s New Character Release PV

Template ID: template.character.release.15s.v1

## Purpose

手游新角色上线、新角色预告、角色 PV 宣传的首选模板。
核心目标：建立角色记忆。

## Default Style

| 属性 | 值 |
|---|---|
| Theme | character-release |
| Style | mobile-game-premium |
| Animation | modern-cel |

## Structure

```
HOOK → IDENTITY → PERSONALITY → ABILITY → TITLE
```

## Shot Plan

| Shot | Time | Purpose | Camera | Content |
|---|---|---|---|---|
| 01 | 0-2s | Hook | reveal-closeup | eyes / face / signature feature |
| 02 | 2-5s | Identity | beauty-showcase | face → hair → outfit → signature item |
| 03 | 5-8s | Personality | medium close | 根据类型选择表情 + 动作 |
| 04 | 8-12s | Signature | action-tracking | ability-release 或 weapon-reveal |
| 05 | 12-15s | Title | final-pose | character name / title / signature pose |

## Component Default

Camera: reveal-closeup / beauty-showcase / hero-low-angle
Action: head-turn / signature-pose / ability-release
Transition: flash-cut / title-reveal

## Validation

- ✓ 第一秒出现角色
- ✓ 15 秒完成角色介绍
- ✓ 有能力展示
- ✓ 有最终记忆画面
- ✓ 角色 DNA 未变化
