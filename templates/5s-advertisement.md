# 5s Mobile Character Advertisement

Template ID: template.mobile.ad.5s.v1

## Goal
短时间获得点击。

## Structure

| Shot | Time | Content |
|---|---|---|
| 01 | 0-1.5s | Hook — face / eye / signature element |
| 02 | 1.5-3.5s | Character Showcase — hair / outfit / pose |
| 03 | 3.5-5s | Memory Frame — hero pose / title |

## Rules

禁止：剧情 / 复杂动作 / 多个角色
优先：视觉冲击
