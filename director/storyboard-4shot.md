# 4 镜头连贯角色 PV 分镜脚本

适配三类风格（打斗 / 日常文戏 / 魔法幻想）通用逻辑。
总时长 13s（可按 `SESSION_SPEC.duration` 等比调整）。

---

## 镜头 1：氛围铺垫 · 静态登场（0-3s）

| 维度 | 内容 |
|---|---|
| 时长 | 3s |
| 景别 | 全景 |
| 镜头运动 | 固定机位，0 位移 0 震动，画面绝对稳定 |
| 画面内容 | 角色独立站立于极简动漫场景中，身姿挺拔，姿态松弛且有气场，面部表情清冷沉稳；背景简化手绘质感，低饱和衬底，无多余杂物干扰主体 |
| 动态表现 | 极致静谧，仅发丝、衣角轻微随风微动，无大幅度动作，铺垫角色氛围感 |
| 转场方式 | 慢速中心光圈收缩转场 |
| 核心 Prompt | 赛璐璐全景，固定机位静态镜头，极简手绘背景，低饱和平涂色调，细微衣物发丝动态，静谧氛围铺垫，12fps有限动画 |

## 镜头 2：姿态特写 · 情绪递进（3-6s）

| 维度 | 内容 |
|---|---|
| 时长 | 3s |
| 景别 | 近景（上半身 + 面部特写） |
| 镜头运动 | 极缓焦距推进，速度 0.2/s，无位移、无晃动 |
| 画面内容 | 聚焦角色上半身与眉眼细节，眼神坚定有神，肢体姿态微微收紧，蓄力氛围感初显；画面预留视线留白，构图舒适规整 |
| 动态表现 | 眼部微眨眼、神情微动，肢体细微蓄力张力 |
| 转场方式 | 人物动作轨迹匹配转场 |
| 核心 Prompt | 赛璐璐人物近景，极缓焦距推镜，面部微表情细节，肢体蓄力细微动态，对称构图留白，柔和光影平涂，复古手绘质感 |

## 镜头 3：能力爆发 · 高光动态（6-10s）

| 维度 | 内容 |
|---|---|
| 时长 | 4s |
| 景别 | 中景 → 全景切换 |
| 镜头运动 | 蓄力慢环绕（30° 小角度），爆发瞬间快速拉镜 + 短时微震（8px 振幅，0.3s） |
| 画面内容 | 角色抬手释放专属能力/战斗招式，肢体动作利落舒展；周身浮现专属咒力/魔法光效/战斗气流，块状手绘特效层次分明，背景轻微虚化突出主体 |
| 动态表现 | 动作轻微挤压拉伸，能力扩散轨迹流畅，搭配手绘速度线/分层粒子特效，爆发帧短暂定格强化高光 |
| 转场方式 | 高光闪白硬切转场 |
| 核心 Prompt | 赛璐璐动态高光镜头，小角度环绕运镜，爆发快速拉镜+短时微震，肢体轻微形变，手绘速度线+块状分层特效，高光帧定格，热血幻想动态质感 |

## 镜头 4：姿态定格 · 收尾留白（10-13s）

| 维度 | 内容 |
|---|---|
| 时长 | 3s |
| 景别 | 全景 |
| 镜头运动 | 震动复位，镜头匀速拉远至全景，随后固定静止 |
| 画面内容 | 角色收尾经典 pose 定格，身姿稳健气场全开，周身特效缓缓消散；画面干净通透，主体突出，适配 PV 结尾留白质感 |
| 动态表现 | 动作静止定格，特效粒子逐层缓慢消散，画面逐步回归静谧 |
| 转场方式 | 慢淡黑淡出收尾 |
| 核心 Prompt | 赛璐璐全景收尾，匀速拉镜后固定机位，角色经典pose定格，特效分层消散，画面干净简洁，复古动画收尾质感 |

## 适配说明

| 类型 | 镜头 1 调整 | 镜头 3 调整 | 镜头 4 调整 |
|---|---|---|---|

| 魔法幻想 | 魔法阵环绕 | 技能释放 + 块状光效 | 魔法阵定格 |
