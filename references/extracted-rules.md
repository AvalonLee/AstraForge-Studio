# 从成功案例中提取的规则

> 来源：`角色pv教程和提示词2.md`、`动漫角色pv教程和提示词.md`、
> `赛璐璐风格三套专属视频Prompt + 四镜连贯分镜脚本.md`


## 一、机位变化规则（核心：避免站桩）

每次角色出现必须同步改变：

1. 镜头高度（俯拍/平视/仰拍/鱼眼/荷兰角）
2. 镜头方向（正面/侧面/背面/45°/旋转）
3. 身体朝向（正面/侧身/背面/前倾/后仰）
4. 手势（叉腰/伸向镜头/撩发/握拳/比心/指点）
5. 腿部姿态（站立/迈步/单膝/坐姿/蹲姿）
6. 表情（改变幅度、情绪、嘴角方向）

**绝不允许**连续两个镜头使用相同机位、相同构图或相同动作。

---

## 二、角色 DNA 一致性强制约束

全片必须保持：

- 发色（禁止自动换色）
- 瞳色（禁止自动换色）
- 服装核心设计（禁止无理由换装）
- 武器/法器（禁止消失或被替换）
- 配饰（禁止消失）
- 角色年龄感（禁止变化）
- 气质（禁止变化）

**禁止**：脸崩、五官变化、发型变化、服装随机变化、肢体畸形、多手多脚、手指错误、穿模、法器消失。

---

## 三、安全边界声明

1. 性感风格限定「气质魅惑自信，非露骨」
2. 必须显式声明「禁止内衣外露、禁止走光、禁止过度裸露、禁止低俗色情表现」
3. 年龄边界必须显式声明（明确为「年轻成年女性」或相应年龄）
4. 禁止未成年外观（如角色设定为成年）、过度暴露、低俗内容

---

## 四、角色与背景分离原则

核心手法：**角色相对稳定 + 背景 Graphic 高速运动**。

- 角色占画面 70%，特效/UI 占 20%，环境占 10%
- 角色在主视觉段稳定居中，背景动态元素高速重组
- 这是控制生成风险、同时保持视觉冲击的关键手法

---

## 五、节奏控制策略

### 打斗

- 0.5s 内切入，无铺垫
- 全程高密度切镜（0.3-0.8s）
- 最后 0.5s 定格 + 标题

### 日常文戏

- 开场 0.5s 内出现角色，但允许 1-2.5s 的舒缓镜头
- 中段 1-2s 一次机位变化
- 最后 0.5s 定格 + 标题

### 魔法幻想

- 蓄力 1.5-2.5s 舒缓铺垫
- 爆发 0.3-0.8s 快切
- 高光特效帧短暂定格
- 最后 0.5s 定格 + 标题

### 通用

- 12.5s 处安排「元素散开留一瞬呼吸感」再重组，避免全程高压导致观感疲劳
- 最后 0.3s：角色眨眼 / 粒子飘散 / 画面定格 → 标题出现

---

## 六、细节快切蒙太奇

把角色卖点「逐项解锁」，比一次性全展示更有记忆点。

顺序：面部 → 发饰 → 耳饰 → 颈部配饰 → 服装 → 手部 → 签名道具

---

## 七、转场方式清单

| 类别 | 具体方式 | 适用 |
|---|---|---|
| 硬切 | 闪白硬切、冲击拉伸、运动轨迹匹配 | 打斗 |
| 图形 | 图形碰撞、漫画分格跳切、速度线推切 | 打斗、Y2K |
| 覆盖 | 贴纸弹出、物体遮挡、文字爆闪 | 日常、Y2K |
| 光效 | 光效形态匹配、能量波纹扩张、粒子飘散遮挡 | 魔法 |
| 结构 | 光圈开合、几何划像、色彩渐变溶解 | 日常、通用 |
| 故障 | 故障闪断、UI 面板插入、噪点抖动、色彩反相 | 赛博、Y2K |

**禁止**：普通淡入淡出、空白过渡、无理由黑场。

---

## 八、多层叠加运动

每帧画面三层结构：

```
前景：贴纸/文字/粒子飞入，提供速度感和即时信息
中景：人物动作核心，表情/姿态/表演
后景：背景图形脉冲/旋转/滚动，提供深度感和节奏
```

三层可独立控制速度与节奏，形成持续不断的视觉推进。

---

## 九、文字元素规则

1. 必须是原创视觉设计感文字，不是现成品牌 Logo
2. 可闪现的平面文字，一闪而过（1-2 帧），不遮挡角色
3. 拟声式短标签（HMPH. / NOT INTERESTED.）强化性格，成本低效果好
4. 文字出现方式：黑粉反相、单帧闪白、爆炸线、字体冲屏、分块撕裂、平面震屏

---

## 十、Prompt 结构规则

1. 图片 Prompt 与视频 Prompt 分离：先用 seedream5.0lite 定角色，再用 H3 做视频
2. 图片 Prompt 需指定模型、比例、数量（建议 2-4 张供挑选）
3. 视频 Prompt 分 10 段结构（见 core/prompt-structure.md）
4. 机位清单式列举（如「高机位俯拍近景 / 超低机位仰拍 / 贴脸超近距离特写」）比抽象描述更有效
5. 角色一致性约束必须显式写出，不让 AI 猜测
6. 安全边界约束必须显式写出

---

## 十一、避坑核心总结

1. 全程坚守赛璐璐核心：**只靠速度线、残影、色块特效做动态，绝对禁止写实运动模糊、流体特效、3D 环绕运镜**
2. 节奏区分明确：打斗快切顿挫、文戏舒缓静谧、魔法快慢结合，**不混用镜头节奏**
3. 所有参数可量化、可直接输入 AI 工具，无模糊主观描述
4. 人物每次重新出现必须改变机位，避免站桩
5. 角色相对稳定 + 背景高速运动 = 控制风险 + 保持冲击
